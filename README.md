# 钻机现场安全联锁台

接入风速、井架倾角、卷扬载荷、可燃气体四路模拟量，按 **安全 / 预警 / 联锁** 三级实时更新的现场安全联锁台。

## 安全联锁逻辑

- **四路独立判级**：风速 13.8 / 20.7 m/s、倾角 1.5 / 3.0°、载荷 1000 / 1400 kN、可燃气体 25 / 50 %LEL 为预警/联锁门限。
- **多风险并存取最高级**：横幅同时列出全部活动预警与联锁通道，互不覆盖；任一路联锁即全场联锁。
- **联锁即锁定**：触发联锁自动锁定提升（卷扬）与回转（转盘），"试操作"会被拒绝并记录。
- **复位双条件**：必须全部风险通道解除 **且** 由值班负责人确认，才能复位；确认后风险反复则确认作废，需重新确认。
- **只增事件流**：触发值、解除值、确认人、时间等写入事件流，每条记录带前一条的 SHA-256（哈希链），界面可做完整性校验、可导出 JSON，不可修改。
- **刷新保持**：未解除的联锁回合与事件流持久化在 localStorage，刷新后保持。
- **失效安全**：启动时状态数据或哈希链校验失败，自动进入红色安全联锁并记录 FAILSAFE 事件，经值班负责人核查确认后方可复位。
- **异常数据按联锁处置**：信号丢失、超物理量程、数据停刷（>5s）、无法解析均按联锁处理。
- **桌面与手机响应式**：均可查看、确认、复位与追溯。

## 本地运行

```bash
npm install
npm run dev        # 开发，端口 5103
npm run build      # 生产构建
npm run preview    # 预览构建产物
npm run test:e2e   # Playwright 浏览器端到端验收（需先 preview）
```

## 验收场景

`e2e/verify.mjs` 覆盖 40 项断言：临界值跳级、并发告警、未授权确认/复位、刷新恢复、四类异常数据、状态/事件流损坏后的安全联锁、手机视口全流程。截图输出到 `shots/`。

页面底部「测试注入台」可手工切换每路通道的正常/预警/联锁/异常模式、注入门限临界值、破坏本地存储数据。

## 技术栈

React 19 + Vite + TypeScript，无其他运行时依赖；加密使用 Web Crypto（SHA-256）。
